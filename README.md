# Muthu Stanly — Portfolio

A single-page personal portfolio site for **Muthu Stanly**, Senior PHP Engineer, built as a static HTML/CSS/JS page styled like a terminal / systems dashboard — dark "galaxy" theme, monospace/robotic typography, and a live JSON-style profile card.

**Live site:** https://muthu-stanly.github.io/portfolio/

## About

Senior PHP Engineer with 7+ years of experience building scalable CRM, ERP, e-commerce, and WordPress web applications using Laravel, CodeIgniter, and WordPress. Focused on REST API development, MySQL performance optimization, and third-party integrations, with hands-on experience in Docker and AI-assisted development workflows.

## Sections

- **Intro** — animated typewriter name reveal, availability status, and a live "profile.json" style summary card
- **Measured Outcomes** — key career metrics (performance gains, response time reductions, client satisfaction, years of experience)
- **Skills** — technical skills organized like a dependency tree (Languages & Frameworks, Frontend, Data & Architecture, Security & Auth, Tools, Deployment & CMS, AI, and more)
- **Experience** — reverse-chronological work history from PHP Developer to Senior Software Engineer
- **Projects** — CRM, ERP, e-commerce, LMS, fintech, and WordPress multi-client projects delivered across roles
- **Contact** — email, phone, and LinkedIn

## Features

- Fully responsive layout (desktop, tablet, mobile) with a fluid, full-width container
- Sticky navigation bar with smooth-scroll section links and a resume download button
- Mobile navigation collapses into a hamburger menu with a slide-down drawer (includes resume download)
- Animated code-style typewriter effect for the name, with a blinking cursor
- Twinkling starfield background on a "galaxy black" theme
- Robotic/sci-fi font pairing (Orbitron for display text, Share Tech Mono for body/code text)
- Graceful fallback message shown if JavaScript is disabled in the browser
- Custom favicon set (favicon.ico, PNGs, Apple touch icon)
- Downloadable resume (PDF) linked from the navigation bar

## Tech Stack

- HTML5
- CSS3 (custom properties, Flexbox, CSS Grid, responsive breakpoints)
- Vanilla JavaScript (no frameworks or build tools)
- Google Fonts — [Orbitron](https://fonts.google.com/specimen/Orbitron), [Share Tech Mono](https://fonts.google.com/specimen/Share+Tech+Mono)
